# Repositório e entrega

O projeto está publicado em:

https://github.com/debieecrincev1/mini-loja-debiee

A implementação foi desenvolvida na branch `feature/mini-loja` e integrada
à `main` pelo [Pull Request #1](https://github.com/debieecrincev1/mini-loja-debiee/pull/1).
O histórico de commits foi preservado.

## Baixar uma cópia

Use **Code > Download ZIP** para baixar os arquivos. Para obter também o
histórico Git:

```bash
git clone https://github.com/debieecrincev1/mini-loja-debiee.git
cd mini-loja-debiee
git log --oneline
```

## Enviar na plataforma

Na atividade **Desafio - Entrega projeto Engenheiro de Dados Junior**, abra
**Entrega do projeto final Engenheiro Dados Junior**. Cole o endereço do
repositório no campo **Cole o link da sua entrega**, clique em **Enviar link**
e confira a confirmação exibida.

A publicação no GitHub está concluída. O envio desse link na plataforma é
uma etapa separada.
